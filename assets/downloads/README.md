# Instaladores de teste

Coloque nesta pasta os executáveis de avaliação publicados no site:

| Arquivo | Página |
| --- | --- |
| `Reobote-PDV-Setup.exe` | `produto-reobote-pdv.html` |
| `Reobote-Cardapio-Digital-Setup.exe` | `produto-cardapio-digital.html` |

Os links de download nas páginas de detalhe apontam exatamente para esses nomes.

> **Nota:** os binários não ficam versionados por padrão (podem ser grandes). Após adicionar os `.exe` nesta pasta, faça commit/push (ou publique via GitHub Releases e atualize os `href` das páginas, se preferir hospedar fora do repositório).
